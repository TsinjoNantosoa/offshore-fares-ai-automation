# n8n workflows

All workflows are generated by `npm run build` (`scripts/build-workflows.js`) into `n8n/*.json` with fixed IDs (`ofwf01…`), imported and published by the `n8n-init` container. Every workflow uses `WF99_ERROR_HANDLER` as its error workflow. Each workflow also contains a sticky note explaining it in the editor.

**Conventions**
- Code nodes start with their own logic, followed by a generated bundle of `lib/` modules (`OF.<module>`). Edit `lib/`, never the bundle.
- Postgres nodes always run `SELECT of_<function>($1::jsonb) AS r;` with the payload in `$json.db`.
- Sub-workflows are called with *Execute Workflow* (wait = true unless noted).
- Webhooks called by the console require the `X-Ops-Token` header (credential *Ops Console Token*).

## Webhook reference

| Method & path | Auth | Body |
|---|---|---|
| `POST /webhook/demo/email` | X-Ops-Token | `{message_id, thread_id, from, subject, body}` (DEMO_MODE only) |
| `GET /webhook/whatsapp` | verify token | Meta handshake |
| `POST /webhook/whatsapp` | HMAC signature | Meta Cloud API payload |
| `POST /webhook/fare-desk/options` | X-Ops-Token | `{rfq_number, entered_by, options[]}` (see `demo/sample-fares.json`) |
| `POST /webhook/fare-desk/mock-options` | X-Ops-Token | `{rfq_number}` (DEMO_MODE only) |
| `POST /webhook/quote/decision` | X-Ops-Token | `{quote_id, action, reviewer, note?, edited?, acknowledge_warnings?}` |
| `POST /webhook/ops/action` | X-Ops-Token | `{action, rfq_number, operator, booking_reference?, alert_id?, message_id?}` |
| `POST /webhook/ops/run-followups` | X-Ops-Token | `{simulate_hours_ahead?}` |
| `POST /webhook/ops/run-sla` | X-Ops-Token | `{}` |

## Changing a workflow
1. Edit `lib/*.js` (logic), `prompts/*.md` (AI instructions) or `scripts/build-workflows.js` (nodes / wiring).
2. `npm test` → `npm run build` → `npm run workflows:reimport` (overwrites the edited workflows in n8n).

Small changes can also be made directly in the n8n editor. In that case, export the workflow and keep it under version control, since a re-import would overwrite it.
